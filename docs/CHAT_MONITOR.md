## Inbox shortcut and compact feed

- Show a pinned virtual system conversation in the client chat inbox only to authenticated SUPER_ADMIN accounts with both required permissions. Selecting it renders the same read-only monitor component as the admin page, without creating a real thread, sending group messages, or fetching monitor data before selection.
- Compact responsive feed with internal scrolling, visible sender and conversation, sender-role filters, local search over loaded messages, and lazy image previews. Both entry points preserve the same server-side guard and password masking.
- Fetch at most 60 rows per request. Load more adds one older cursor page and freezes its upper boundary, with a maximum of 120 rows in the displayed window. Continue to the next older window at the cap; return to newest for live updates. Revalidate the mounted window every four seconds, including password masking; clear previously displayed content on request failure. No full-history fetch or persistent cache.
