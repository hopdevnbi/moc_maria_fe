# Homepage first-visit 99K promotion

Replaces only the homepage Noel invitation with the owner-provided square poster. No expiration was provided for this promotion, so it is independent of the Noel campaign API; Noel gift events and routes remain unchanged. The new session key displays this poster once per browser tab after 1.2 seconds. The booking CTA opens /dat-lich without modifying service prices or eligibility.

Static WebP 768 and 1200 pixel variants (121086 and 216818 bytes) with JPEG fallback preserve the full artwork. Native modal dismissal, scroll lock, focus restoration, safe-area-aware dynamic viewport dimensions, 44px close button and 48px booking CTA support touch and keyboard use. The image is never cropped.

Local targeted unit tests: 6 passed. TypeScript check passed. No business data changes.
